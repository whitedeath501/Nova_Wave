Bem-vindo ao sistema NovaWave

Este é um protótipo de um sistema interno de gestão empresarial para uma empresa fictícia de e-commerce. Ele simula a estrutura de um sistema real utilizado por empresas para organizar setores, usuários, cargos, projetos e tarefas.

O objetivo deste projeto é demonstrar como um sistema corporativo pode ser estruturado de forma modular, escalável e com separação de responsabilidades entre diferentes áreas da empresa.

Utilize o menu superior para acessar as funcionalidades disponíveis no sistema, como gestão de usuários, controle de projetos e acompanhamento de tarefas.
